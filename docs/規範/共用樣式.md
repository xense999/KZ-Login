# 共用樣式 — 主題 token 與跨頁 class

歸屬見 [模組歸屬總表](../規範.md) 的 `共用樣式` 條。

（2026-09-14 首次建檔。）

## 公開介面

- 主題 token（`--bg`、`--surface`、`--text`、`--border`……），亮色在 `:root`，暗色在 `:root[data-theme="dark"]`。
- 跨頁 class：`.titlebar`、`.wbtn`（主視窗與帳號瀏覽器共用）；`.bottom-bar`（主頁與兩種登入頁的底部按鈕列，2026-09-14 從 MainPage 抽出）、`.btn-ghost`、`.btn-solid`（登入頁按鈕，2026-09-14 從 QrPage 抽出）。

## 不變量

- 同一種外觀出現在第二個頁面時就抽到這裡，頁面內不留同義副本。
